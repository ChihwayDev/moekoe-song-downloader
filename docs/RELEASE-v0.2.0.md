## MoeKoe 歌曲下载 v0.2.0

个人学习研究项目，用于探索 MoeKoe Music 插件开发、音频接收和本地文件保存。

### 功能

- 面板可拖动并记住位置，提供左侧、居中、右侧预设。
- 支持当前歌曲、完整歌单和勾选部分歌曲下载。
- 系统窗口选择保存目录，歌单可单独创建文件夹。
- 标准、320 kbps、FLAC、Hi-Res 和最高可用音质选择。
- 下载进度、取消、同名文件后缀及单曲失败原因显示。

### 安装

适用于 Windows 版 MoeKoe Music 1.7.1。

1. 下载附件 `moekoe-song-downloader-v0.2.0.zip`。
2. 在 MoeKoe 的设置 → 插件中导入；已有 0.1.0 时先卸载旧版本。
3. 授权本插件的本地保存组件 `song-downloader-saver`。
4. 完全退出并重启，再从播放器的下载按钮进入。

### 能力范围与验证

音频及音质来自当前账户和客户端配置的接口返回。插件使用播放资源地址，当前没有单独核验平台下载权益，也没有实现 DRM 解密。试听资源保存后仍是试听内容。请仅处理你有权保存的音频。

当前版本已在本地通过 33 项自动测试及 14 项独立客户端验证，采用本地生成的测试音频和接口数据。没有据此宣称所有在线歌曲或账户权限均已验证。新加入的 GitHub Actions 工作流需上传仓库后查看实际运行结果。

附件中的插件 ZIP 包含 Windows 保存程序；GitHub 自动生成的源码 ZIP 不含该编译文件。

项目采用 **GPL-2.0-only**。附件 `moekoe-song-downloader-v0.2.0-source.zip` 提供对应源码、许可证、测试和构建脚本。
