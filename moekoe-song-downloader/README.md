# MoeKoe 歌曲下载 0.2.0

适用于 **Windows 版 MoeKoe Music 1.7.1**。

本项目以个人学习研究和技术交流为目的，主要探索播放器扩展、音频接收和本地文件保存。插件使用接口返回的播放地址；当前没有单独核验平台的下载权益，也没有实现 DRM 解密。请仅处理你有权保存的音频。

## 更新与安装

1. 在 MoeKoe Music → 设置 → 插件中，卸载原来的「MoeKoe 歌曲下载」0.1.0。
2. 点击「安装插件」，选择 `moekoe-song-downloader-v0.2.0.zip`。
3. 在本插件的「本地二进制可执行程序权限」区域，授权 **song-downloader-saver**。
4. 完全退出并重新启动 MoeKoe Music。
5. 播放一首在线歌曲，点击播放器上的 **↓** 按钮。

本地保存组件由 MoeKoe 的插件系统启动并管理，用于将音频写入用户选择的文件夹。源码在开发项目的 `native/SongSaver.cs` 中。

## 面板位置

默认显示在左侧，避开右侧播放列表。可以拖动面板标题栏，松开后自动记住位置；关闭、重启后继续使用上次位置。标题栏的下拉菜单可重置到左侧、居中或右侧。窗口缩小时，面板会限制在可见区域。

## 单曲下载

1. 选择「单曲下载」。
2. 在「保存到」点击「选择…」，用系统文件夹选择器指定目录。
3. 选择下载音质，再点击「下载当前歌曲」。

也可以在歌单模式中只勾选一首歌曲；这种方式无需先播放该歌曲。

## 按歌单下载

1. 选择「歌单下载」。
2. 点击「刷新」读取自己创建或收藏的歌单，选择一个后点击「读取」。也可在客户端打开歌单，再点击「读取当前页面歌单」。
3. 默认全选整个歌单，可取消全选后单独勾选歌曲。每页显示 100 首；下载包含所有已勾选歌曲。
4. 选择音质和保存文件夹。可勾选「以歌单名创建子文件夹」。
5. 点击「下载所选 N 首」。歌曲按顺序下载，列表显示每首的保存结果或失败原因。

还支持输入歌单 ID，或粘贴带 `global_collection_id` 参数的歌单页面链接。播放队列和歌单是不同的数据来源，此版本的歌单功能读取完整歌单，而非只读取屏幕上可见的歌曲。

## 下载音质

| 选项 | 行为 |
| --- | --- |
| 当前播放音质 | 单曲模式可用，保存当前播放器已经获得的音频地址 |
| 标准 128 kbps | 请求该歌曲的标准音质资源 |
| 高品 320 kbps | 请求该歌曲的高品音质资源 |
| 无损 FLAC | 请求该歌曲的无损资源 |
| Hi-Res | 请求该歌曲的 Hi-Res 资源 |
| 最高可用音质 | 按 Hi-Res、FLAC、320、128 的顺序选择接口标记可用的最高一档 |

音质选择独立于播放器的播放设置。插件沿用当前登录账户及客户端配置的 API 来获取资源；可用音质由歌曲资源及账户权限决定。明确指定的音质不可用时，会标记失败，**不会自动降为其他音质**；批量任务继续处理后面的歌曲。需要账户验证时会停止批量任务，处理后可重新开始。

## 保存行为

- 保存文件夹、两种模式各自的音质和面板位置会记住。
- 取消系统文件夹选择器会保留上一次选择。
- 音频边接收边写入临时文件；校验完整性及实际文件头后才更名为正式歌曲文件。
- 文件名为 `歌手 - 歌名.实际格式`；同名文件添加 `(1)` 等后缀，保留原文件。
- 「已保存」表示文件已实际写入所选文件夹。单曲成功提示显示完整路径。
- 可取消当前任务。已保存的歌曲保留，未完成的临时文件会清理。
- 关闭下载面板或插件设置弹窗时，任务继续。完全退出或重载客户端主窗口会停止进行中的任务。

此版本使用 Windows .NET Framework 本地保存组件，不需要另装 Node.js 或 Python。单文件上限 2 GB，支持 MP3、FLAC、M4A、AAC、OGG、Opus、WAV、APE 和 WavPack 文件头。保存原始资源，不执行转码；试听地址对应的内容也仍然是试听内容。暂不导出歌词、封面或 HLS 分段流。

## 实现与验证

通过 MoeKoe 官方的 native-host 接口管理保存组件，不更改主程序。歌曲接口支持安装版 1.7.1 的本地 HTTP API，也支持后续源码中的 `kugouapi.request` 接口。账户信息仅随客户端原有歌曲 API 请求使用，不传给音频保存组件；音频 CDN 请求不附带账户 Cookie。

开发项目提供单元验证、原始客户端运行环境的集成验证、完整源码和重新打包脚本。测试采用本地生成的真实 WAV、两档 MP3 及两档 FLAC 音频；不需要登录实际音乐账户。在线歌单内容和音质权限仍以当前账户的接口返回为准。
